这里是静态网站发布仓库，开发代码和完整数据库保持在私有协作仓库中。

网站数据是官方来源的论文标题、摘要、作者、主题匹配依据和统计结果，不包含论文全文、审核CSV、数据库、访问凭据或采集运行日志。网页与JSON作为经过本地校验的Release压缩包发布，不进入Git历史。

部署只由维护者明确触发：读取指定Release，校验压缩包SHA-256、文件白名单、分片版本与每个文件的哈希后，通过GitHub Pages原子发布。失败不替换之前的有效网站。这个工作流不采集数据，不安装周更任务。
